# Жәңгір ханның ағартушылық мұрасы

Ғылыми зерттеу, тарихи макет, зерттеу күнделігі, қосымша сабақтардың 9 тақырыптық жоспары және интерактивті тапсырмалар.

## Жариялау

Settings → Pages → Deploy from a branch → main → / (root) → Save.

Сайттың барлық файлдары репозиторийдің түбірінде орналасқан. Қосымша орнату немесе жинақтау қажет емес.
