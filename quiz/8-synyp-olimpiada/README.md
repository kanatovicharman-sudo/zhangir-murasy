# Тарих алаңы — 8-сынып олимпиадасы

Қазақстан тарихынан мұғалім ұсынған бес DOCX негізіндегі ашық куиз.

## Құрамы

- Аудандық кезең — 30 сұрақ; бірдей екінші файл бір рет енгізілді.
- Облыстық/қалалық кезең — 30 сұрақ.
- Олимпиада жинағы — 30 сұрақ. Файл атауында Republican, ішкі тақырыбында аудандық кезең көрсетілгендіктен, ресми республикалық кезең деп белгіленбеді.
- 2-айналым — 30 сұрақ, бастапқы жауап нұсқалары сақталған.

Жауап кілттеріндегі 90 сұрақтың балама нұсқалары жаттығу үшін құрастырылды. Барлық сұрақта файл атауы, бастапқы нөмірі, бастапқы сұрағы және бастапқы кілті data.json ішінде сақталған. Сайт ресми олимпиада нұсқасының дәл көшірмесі ретінде ұсынылмайды.

## Режимдер

Үйрену, уақытпен сынақ, қателерді қайталау, жеке белгіленген сұрақтар, іздеу, салмақталған ұпай, нәтижені TXT ретінде жүктеу. Деректер браузердегі localStorage ішінде сақталады; серверлік рейтинг немесе тіркелу жоқ. Сынақтың уақыты әр сұраққа 1 минут, беттен шыққанда немесе бетті жаңартқанда бастапқы deadline сақталады.

Барлығы 120 сұрақ; 119-ы бағаланады. Аудандық №12 сұрағындағы 1915 жыл мен Қарсақпай оқиғасының байланысы расталмағандықтан, ол ұпайсыз талқылау ретінде сақталды және сынақ режиміне кірмейді. Жинақтардың мүмкін ұпайлары: 49 + 50 + 50 + 30 = 179. Үйренудегі ұпайсыз сұрақ жауаптарының дұрыстығын статистика есептемейді.

## Нақтыланған деректер

Ескертулер data.json ішіндегі corrections массивінде және сайттың «Материалдар туралы» бетінде берілген. Өзгерістер бастапқы жазбаны өшірмейді.

- Қарқаралы петициясында іс қағаздарын қазақ тілінде жүргізу талабы: https://e-history.kz/kz/news/show/339954
- Қоқан автономиясы үкіметінің алғашқы басшысы М. Тынышпаев: https://e-history.kz/kz/amp/news/show/2299
- Корейлерді депортациялау 1937 жылы: https://assembly.kz/ru/ethnos/ru/koreytsy/
- 1928 жылғы алғашқы ЖОО — қазіргі Абай атындағы ҚазҰПУ-дың негізі: https://www.kaznpu.kz/kz/4338/press/
- Баласағұн датасының екіұштылығына байланысты ғасырмен тұжырымдау: https://e-history.kz/ru/map/view/82
- 1915 жылғы ереуіл туралы салыстыру: https://e-history.kz/ru/history-of-kazakhstan/show/9205
- Аудандық №5 және №7 бойынша салыстыру: https://e-history.kz/media/scorm/126/text/text.htm

## Құрылымы және тексеру

Құрастыру қадамы жоқ. index.html, style.css, data.js, core.js және app.js — өзара салыстырмалы жолмен байланысқан статикалық файлдар. Сыртқы қаріптер немесе API қажет емес. Сайтты жергілікті ашуға да болады.

```sh
node --test test-core.cjs
node --check app.js
```

GitHub Pages main тармағының түбірінен жарияланады. Осы бет жеке quiz/8-synyp-olimpiada/ бумасында орналасқан. Репозиторийдің басқа беттерін өзгерту талап етілмейді.
