# Қазақстан тарихы 5 сынып 330 сұрақ

Қазақ тіліндегі олимпиада куизі. 11 жүктелген файлдағы 330 сұрақ пен 1650 жауап нұсқасы сақталған. Сұрақтар жылдар мен кезеңдерге бөлінбей, аралас беріледі.

Куиз: https://kanatovicharman-sudo.github.io/zhangir-murasy/quiz/330/

Жаттығу және сынақ режимдері, 30/50/100/330 сұрақты таңдау, нәтижені сақтау, қате сұрақтарды қайталау және сұрақтардан іздеу бар. Аккаунт қажет емес. Нәтиже осы браузерде сақталады.

17 қайшы жауап кілті дереккөздермен тексеріліп түзетілді. Нақтылауды немесе толық материалды қажет ететін 22 тапсырма сақталған, бірақ ұпайға қосылмайды. 308 бағаланатын сұрақтың ең жоғары ұпайы — 495.

## Кейін өзгерту

Куиздің «Өңдеу» бөлімінде сұрақ пен жауап нұсқаларын түзетіп, «Өңделген HTML жүктеу» түймесін басыңыз. Барлығына ортақ өзгеріс үшін осы қалтадағы index.html файлын жаңа HTML-мен жаңартыңыз. JSON файлын да импорттап/экспорттауға болады.

questions.json — қазақша сұрақтардың бөлек көшірмесі. index.html дәл осы деректерді ішіне енгізіп сақтайды; тек JSON-ды өзгерту жарияланған HTML-ді автоматты өзгертпейді.

index.html файлын жүктеп алып, браузерде интернетсіз де ашуға болады. Сыртқы ғылыми сілтемелер үшін интернет қажет. Браузердегі визуалды сынақ жүргізілмеген; сұрақтар толықтығы, ұпай есебі және интернетсіз жұмыс логикасы тексерілген.
