# Қазақстан тарихы · 5 сынып · Олимпиадаға дайындық

Қазақ тіліндегі интерактивті дайындық материалы. Негізі — НЗМ, 2017 оқулығы бойынша мұғалімге дайындалған жинақ.

- 7 тарау және 32 тақырып
- 64 тақырыптық тапсырма, 20 тест, 8 жазбаша тапсырма
- Толық жауаптар, бағалау шарттары, хронология және салыстыру кестелері
- Екі оқулық суреті және түпнұсқа Word жинағы
- Барлық бастапқы мәтінді сақтайтын «Толық жинақ» бөлімі

Оқу барысы мен жауаптар оқушының өз браузерінде сақталады. Жазбаша бөлімдегі белгілер — өзіндік бағалау; қорытынды тексеруді мұғалім жүргізеді.

Бұл бума GitHub Pages арқылы репозиторийдің негізгі бетінен бөлек `/olimpiada-5/` мекенжайында ашылады. Орнату және жинақтау қажет емес. Негізгі файл — `index.html`.
